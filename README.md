# 🌸 FLEUR -- Веб-приложение для цветочного магазина

Учебный проект, разработанный в рамках изучения ASP.NET Core MVC.
Веб-приложение представляет собой каталог цветочного магазина с возможностью
просмотра ассортимента, оформления заказов и управления контентом.

##  О проекте

Данный проект создан в учебных целях для закрепления навыков разработки
веб-приложений на платформе **ASP.NET Core** с использованием паттерна **MVC**
(Model-View-Controller).

### Основные возможности:
- 💐 Просмотр каталога цветов и букетов
- 📰 Страницы с информацией о магазине
- 🛒 Оформление заказов
- 👨‍💻 Панель управления администратора
- 🎨 Адаптивный дизайн (HTML + CSS)

---

## 🛠 Технологии и инструменты

| Технология | Назначение |
|---|---|
| **C# / ASP.NET Core MVC** | Серверная логика и архитектура приложения |
| **HTML5** | Разметка веб-страниц |
| **CSS3** | Стилизация и оформление |
| **JSON** | Конфигурация приложения (`appsettings.json`) |
